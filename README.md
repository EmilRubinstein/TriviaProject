# Magshimim Trivia Project

A C++ / C# multi-threaded client-server trivia application developed as part of the **Magshimim** cybersecurity and software engineering program. The system allows multiple concurrent users to register, log in, create or join trivia game rooms, and answer questions in real time via a custom binary/text protocol over TCP sockets.
